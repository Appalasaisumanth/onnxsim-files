// ── Memory footprint comparison (why S=1 matters) ────────────────────────────
//
// mamba-130m, d_inner=1536, d_conv=4, d_state=16, float16:
//
//   OLD (S=8192):
//     conv_state: 8192 * 1536 * 4  * 2 bytes = 100.7 MB  per block
//     ssm_state:  8192 * 1536 * 16 * 2 bytes = 402.7 MB  per block
//     Total for 24 blocks: 24 * 503 MB = ~12 GB  ← the 6x blowup
//
//   NEW (S=1):
//     conv_state: 1    * 1536 * 4  * 2 bytes = 12.3 KB  per block
//     ssm_state:  1    * 1536 * 16 * 2 bytes = 49.2 KB  per block
//     Total for 24 blocks: 24 * 61.5 KB = 1.5 MB  ← correct
//
// The 6x vs OPT is because OPT's KV cache for 8192 tokens with d_model=768,
// 12 heads, 12 layers is roughly: 2 * 8192 * 768 * 12 * 2 bytes = 288 MB.
// Mamba at S=1 has ~1.5 MB of state — orders of magnitude smaller.
